# 💰 AI-Powered Personal Finance Tracker

An intelligent personal finance management application built with Python, Streamlit, Pandas, and Machine Learning.

This project helps users track income and expenses, analyze spending patterns, manage budgets, and automatically categorize expenses using Natural Language Processing (NLP).

---

## 🚀 Features

### 💳 Transaction Management

* Add income and expense transactions
* Delete transactions
* Store transaction history
* Export financial reports as CSV

### 📊 Financial Analytics

* Total Income Dashboard
* Total Expense Dashboard
* Savings Calculator
* Expense Breakdown Pie Chart
* Expense Trend Visualization
* Monthly Budget Tracker

### 🤖 AI-Powered Expense Categorization

Uses a Naive Bayes Machine Learning model to automatically classify expenses based on transaction descriptions.

Examples:

| Description      | Predicted Category |
| ---------------- | ------------------ |
| Swiggy Order     | Food               |
| Uber Ride        | Travel             |
| Amazon Purchase  | Shopping           |
| Electricity Bill | Bills              |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/niketan-jogani/AI-Finance-Tracker.git
```

Move into the project directory:

```bash
cd AI-Finance-Tracker
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

---

## 🧠 Machine Learning Workflow

1. User enters an expense description.
2. The text is processed using NLP techniques.
3. The trained Naive Bayes model predicts the category.
4. The expense is automatically classified and stored.
